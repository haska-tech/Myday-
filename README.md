# MyDay

Offline-first Android day planner for personal and professional life.

## Product requirements
- Africa/Kampala timezone; English interface
- Navy, white and lime visual identity
- My Day, Tasks, Calendar, Insights and Settings
- Three daily priorities, timetable, quick task capture and progress
- Local-first/offline data storage
- Small, medium and large home-screen widgets
- Reminders, recurring tasks, voice capture, time tracking and Pomodoro
- Smart rescheduling suggestions always require user approval

## Development status
Initial Kotlin/Jetpack Compose application scaffold. Feature implementation and verification will proceed incrementally.
